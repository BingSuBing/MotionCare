# 동승자 웹 화면 명세 (v2)

> 기준: 스키마 v0.3.2 (`docs/firestore-schema.md`), 피그마 "모바일 페이지 수정문서" (2026-11-14)
> 바뀐 점: **처음 설정 4단계 → 3단계**, 시각 케어(점·수평선)는 처음 설정에서 빠지고 **메인에서 따로** 켜요.

## 경로

QR 주소는 `/join?session=<id>` 하나예요. 접속하면 상태를 보고 알맞은 화면으로 보내요.

| 경로 | 화면 | 상단 번호 |
|---|---|---|
| `/join?session=:sid` | 분기 | |
| `/s/:sid/name` | 이름 입력 (피그마 없음) | |
| `/s/:sid/welcome` | 초대 받기 | |
| `/s/:sid/seat` | 처음 설정 1: 좌석 | 01 / 03 |
| `/s/:sid/sensitivity` | 처음 설정 2: 멀미 정도 | 02 / 03 |
| `/s/:sid/climate` | 처음 설정 3: 실내 취향 → **제출** | 03 / 03 |
| `/s/:sid/done` | 제출 완료 | |
| `/s/:sid/home` | 메인 (이동 중) | |
| `/s/:sid/care` | 나만의 케어 (시각 케어) | |
| `/s/:sid/discomfort` | 불편 알리기 | |
| `/s/:sid/sent/:requestId` | 전달 완료 | |

### 진입 분기

1. 익명 로그인 → 세션 구독. 없으면 "세션을 찾을 수 없어요", `active === false`면 "이동이 끝났어요"
2. `passengers`에서 `uid == 내 uid` 문서 찾기
   - 없음 → 이름 입력
   - 있음 + `submittedAt == null` → 멀미 정도
   - 있음 + `submittedAt` 있음 → 메인
3. 좌석이 없는데 멀미 정도 이후 화면으로 오면 이름 입력으로 보내요.

### 공통

- 사람 이름은 `honorific(name)` → "현아 님". 이름·운전자·차량 번호는 전부 데이터에서 읽어요.
- 하단 캡션은 없어요.

---

## 이름 입력

- "어떻게 불러드릴까요?", 입력칸 1개(10자), "시작하기" → 초대 받기
- 좌석 등록 전까지 `sessionStorage`에 보관

## 초대 받기

- 제목 "`{driverName}` 님의 초대를 받았어요", 설명 "`{carNumber}`의 편안타에 참여할게요." (차량 번호 없으면 "편안타에 참여할게요.")
- **사진 없음.** 연초록 카드: 차 아이콘 + `tripTitle` + "✓ 연결됨" 배지, "`{driverName}`님의 차량에서 초대했어요."
- 안내 3줄: 내 좌석과 취향을 알려주세요 / 멤버와 차량 환경을 함께 조율해요 / 불편할 땐 가볍게 요청해요
- "내 좌석 선택하기" → 좌석

## 처음 설정 1/3: 좌석

- 2×2 좌석 칸 (실시간)
  - 운전석: 제목 `driverName`, "선택 불가"
  - 다른 사람 좌석: 제목 **그 사람 이름**, "사용 중"
  - 내가 고른 좌석: 좌석 이름, "선택됨"
  - 빈 좌석: 좌석 이름, "선택 가능"
- 위쪽 막대 안에 "차량 앞쪽", 범례 칩 2개(사용 중 회색, 선택 가능 흰색)
- "이 좌석으로 계속" → **트랜잭션 등록** (스키마 5.1) → 멀미 정도

## 처음 설정 2/3: 멀미 정도

- 제목 "멀미 정도를 알려주세요", 4단계(필수) + "함께 알려주세요 · 선택" 2개
- "실내 취향 설정하기" → `sensitivity`, `sicknessTriggers` 저장 → 실내 취향

## 처음 설정 3/3: 실내 취향 → 제출

- 희망 온도(카드 밖 제목, 18~26℃), **바람 세기**(1단·약하게 / 2단 / 3단), **바람에 민감한가요?**(직접 바람은 싫어요 / 괜찮아요), 정기 휴식 알림(토글 + 30/60/90분)
- 바람 세기·민감도는 **차량을 직접 제어하지 않고** 취향 조율(가중치) 참고용으로 저장해요.
- "내 설정 제출하기" → `desiredTemp`, `fanPreference`, `avoidDirectWind`, `restIntervalMin`, **`submittedAt`** 저장 → 제출 완료

## 제출 완료

- 제목 옆 원형 체크, "`{이름}` 님의 취향을 차량에 전했어요."
- 요약 카드 "`{이름}` (`{좌석}`)" + 제출 완료 배지: 멀미 민감도 / 희망 온도 / 희망 풍량 / 휴식 알림
- 피그마의 "함께 조율한 추천"은 **다른 내용으로 바뀔 예정**이라, 그 자리에 "모두의 희망 온도"(중앙값 + 상태 배지)를 둬요.
- "실시간 케어 확인하기" → 메인

## 메인 (이동 중)

- 제목 "`{driverName}` 님과 이동 중이에요", 설명 "`{carNumber}`의 편안타에 참여 중이에요."
- 현재 실내 환경: `cabinTemp(hvacState)` + 외기/내기
- **희망 온도**: 메인에서 바로 ± 조절, 0.8초 뒤 저장 ("차량에 전달됨")
- 시각 케어 카드: 꺼져 있으면 "움직이는 점 케어 시작하기", 켜져 있으면 "방식 바꾸기" → 나만의 케어
- 휴식 알림 카드: 누르면 펼쳐져서 토글·30/60/90분으로 **알림 시간 바꾸기**
- "내 설정 바꾸기 →" → 멀미 정도부터 다시
- **큼지막한 "불편해요" 버튼** → 불편 알리기

## 나만의 케어 (시각 케어)

- 네, 사용할래요 / 아니요, 괜찮아요 + 안내 방식(움직이는 점 / 수평선 / 최소 시각 신호)
- **"이대로 계속하기"** → `visualMode` 저장 → 메인으로 돌아가고, 화면에 점·수평선 안내 표시 (`feature/web-motion-cue`, Android는 다른 앱 위 오버레이)

## 불편 알리기

- 메스꺼워요 / 너무 추워요 / 너무 더워요 / **바람이 너무 세요**(`windy`) / 잠깐 쉬고 싶어요
- 선택에 맞는 안내 카드, "`{명사}` 요청 보내기" → `requests`에 `REPORT_DISCOMFORT` → 전달 완료

## 전달 완료

- 요청 구독. 배지 "HH:MM · `{라벨}`", `status === "done"`이면 "운전자 확인됨"
- 도와드리는 단계 (종류별): 차량 화면에 요청 표시 / 영상 일시 정지 · 환기 제안(메스꺼워요) / 온도 조정 제안(추워요·더워요) / 바람 조절 요청(바람이 너무 세요) / 가까운 휴식 장소 추천(메스꺼워요·쉬고 싶어요)
- "내 케어 상태로 돌아가기" → 메인
- 피그마 메모: 더 깔끔하게 바뀔 예정
